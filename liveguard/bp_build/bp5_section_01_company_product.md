# §1 公司与产品概述

## §1.1 公司一句话

**守播 LiveGuard** 是一家专注于**直播间 AI 实时合规监控**的企业级 SaaS 公司。我们用计算机视觉、声纹识别与行为理解算法，
对正在进行的直播间进行**秒级、自动化、可取证**的在岗与合规监测，把"主播是否真人在岗、是否挂播空播、是否替身/数字人代播、是否触发违规话术"
这类原本依赖人工巡检的判断，转化为可规模化、可审计的实时信号。

## §1.2 我们解决的核心痛点

| 角色 | 痛点 | 守播提供的价值 |
|------|------|---------------|
| **直播平台 / 治理团队** | 海量直播间无法人工 7×24 巡检；令117号要求平台压实主体责任 | 实时风险打分 + 自动告警 + 处置取证链，覆盖率从抽检升至全量 |
| **MCN 机构** | 旗下数十至数百主播，挂播/替身/违规话术导致扣分、封号、商誉损失 | 集中式监控看板，按账号/时段量化合规风险，事前拦截 |
| **品牌 / 商家自播** | 店播间无人值守易被判挂播；代运营真实性难核验 | 在岗证明 + 违规预警，保住流量与店铺权重 |
| **监管 / 第三方** | 缺乏独立、可取证的合规监测工具 | 中立第三方监测数据与合规报告 |

## §1.3 产品形态

![守播 LiveGuard SaaS 控制台](liveguard/docs/images/liveguard_dashboard.png)

- **核心产品（Y1 主打）**：直播间实时监控 SaaS——接入直播流（拉流 / 平台 API / 边缘盒子），输出风险事件、告警与取证片段。
- **三层交付**：`Edge`（边缘轻量推理，降低带宽与时延）→ `Cloud`（多模态算法与风险引擎）→ `Notify`（多通道告警与处置闭环）。
- **三档订阅**：Starter（长尾主播/小商家）、Pro（MCN/品牌）、Enterprise（平台/大型 MCN，支持私有化）。

## §1.4 风险监测能力清单

| 风险类型 | 监测手段 | 难度 |
|---------|---------|------|
| 离岗 / 无人在岗 | 人脸 + 人形检测，连续无人计时 | ★ |
| 挂播 / 空播（循环视频回放）| 帧间一致性 + 时序异常检测 | ★★★ |
| 替身 / 换人代播 | 人脸比对 + 行人 Re-ID | ★★ |
| AI 数字人 / 照片静帧 | 活体检测 + 帧间微动分析 | ★★★ |
| 违规话术 / 极限词 | 语音转写 + 声纹归属 + NLP 风控（增长期上行）| ★★ |

> **定位声明**：v5.0 以"实时监控本体"为第一产品。风控 OS（话术/价格/商品造假风控）、可信数据网络/API、合规履约保险/RegTech
> 三层扩展作为**增长期可选上行**（见 §5.5 与 §11 上行情景），不计入主口径 TAM 与收入预测，以保持机构 BP 的口径保守与可验证。
