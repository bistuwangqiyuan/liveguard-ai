# §5 商业模式与定价

> 数字来自 `08_pricing_model.py`。

## §5.1 收入模式

订阅制 SaaS 为主（监控单品），辅以按量加路、API/平台分润、私有化/硬件：

| 收入来源 | Y1 | Y3 | Y5 |
|---------|---:|---:|---:|
| SaaS 订阅 | 88% | 76% | 68% |
| 按量付费 / 加路 | 5% | 12% | 14% |
| 平台分润 / API | 3% | 8% | 13% |
| 硬件 / 私有化 | 4% | 4% | 5% |

## §5.2 三档定价

| 档位 | 月费 | 年费 | 客户占比 | 月流失 | ARPU 贡献 |
|------|----:|----:|------:|----:|------:|
| Starter | ¥199 | ¥2,388 | 68% | 4.5% | ¥1,624 |
| Pro | ¥599 | ¥7,188 | 27% | 2.2% | ¥1,941 |
| Enterprise | ¥12,500 | ¥150,000 | 5% | 0.7% | ¥7,500 |
| **加权年 ARPU** | | | | | **¥11,065** |

![定价与价格弹性](liveguard/docs/images/charts/fig_08_pricing.png)

> 价格弹性 Starter 1.5（弹性高）、Pro 0.8、Enterprise 0.4（弹性低），定价采取"长尾走量 + 头部价值定价"。

## §5.3 客户 ROI（采购理由）

监控避免的"挂播扣分/封号/流量损失"远高于订阅费——这是采购的核心驱动（详见 §8）：

| 客群 | 年保护 GMV | 年节省损失 | 年费 | ROI |
|------|---------:|---------:|----:|---:|
| 个人主播/小商家 | ¥216 万 | ¥18.1 万 | ¥2,388 | **75×** |
| 中型 MCN/品牌自播 | ¥1,260 万 | ¥105.8 万 | ¥7,188 | **146×** |
| 头部 MCN/大型电商 | ¥7,920 万 | ¥665.3 万 | ¥15 万 | **43×** |

## §5.4 留存（保守口径）

- 加权月流失 3.69%；金额口径 GRR ≈ 84%（Starter 走量导致 logo 口径流失偏高，金额口径稳健）。
- NRR 由 Y1 96% 升至 Y5 **130%**（净扩张 = 加路 + 升档 + API），低于早期版本的乐观峰值，符合监控单品的扩张节奏。

## §5.5 增长期可选上行（不计入主案）

> 在监控基础上，可逐步展开三层扩展（令117号同样驱动）：
> ① 风控 OS（话术/极限词/价格/商品/刷单造假风控）② 可信数据网络 / API ③ 合规履约保险 / RegTech。
> 该上行可将 TAM 放大至约 ¥386 亿（×2.4，见 §2.4.3），但**本计划书的收入、估值、回报预测均不依赖该上行**，仅作潜在第二曲线披露。
