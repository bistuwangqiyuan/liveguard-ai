# §4 产品与技术

> 全部技术指标来自 `16_tech_benchmark.py`（端到端调优后中位值）与 `04_slo_latency_budget.py`。

## §4.1 系统架构（Edge / Cloud / Notify）

![Edge / Cloud / Notify 三层架构](liveguard/docs/images/liveguard_architecture.png)

- **Edge 边缘层**：拉流/平台 API/边缘盒子（BOM ≈¥1,100）就近抽帧与轻量推理，降低带宽与时延。
- **Cloud 云层**：多模态算法栈 + 风险引擎 + 取证存储；单 GPU 节点（L40/国产替代级）服务约 120 路 1080p。
- **Notify 通知层**：多通道告警（站内/IM/Webhook）+ 处置闭环 + 可审计合规报告。
