# §6 进入市场策略 (Go-To-Market)

> 客户增长路径与 `07_growth_cohort.py` 严格一致：付费账号 Y1 800 → Y5 105,000。

## §6.1 三阶段 GTM

| 阶段 | 时间 | 重点客群 | 获客打法 |
|------|------|---------|---------|
| **楔入（Wedge）** | Y1 | 中型 MCN + 品牌自播 | 令117号合规焦虑驱动；标杆 KA 直签 + ROI 演示（避免封号损失）|
| **扩张（Expand）** | Y2–Y3 | 头部 MCN + 平台治理团队 | KA 深耕 + 私有化；行业协会/合规峰会背书 |
| **规模化（Scale）** | Y4–Y5 | 长尾主播 + 海外 | PLG 自助 + 渠道/ISV 分销 + 平台生态 API |

## §6.3 获客效率（详见 §8）

- 分客群 LTV/CAC：Starter 9.9×、Pro 17.8×、Enterprise 58.4×；各档回收期 ≤ 3 个月。
- 混合获客回收期随客群下沉与 KA 占比变化在 Y1–Y5 区间 3.6 → 28.6 个月（Magic Number 仍 ≈1.3，详见 §9）。

## §6.4 渠道与生态

- **平台合作**：与主流平台治理团队共建合规接口（首 2 年 BD 预算 ¥500 万）。
- **行业协会 / 监管**：以中立第三方身份参与合规标准与典型案例，建立公信力。
- **ISV / 代运营**：嵌入直播代运营与电商 SaaS 生态分销。
