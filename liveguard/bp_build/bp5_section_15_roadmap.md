# §15 路线图与里程碑

## §15.1 产品与商业里程碑

| 阶段 | 时间 | 产品里程碑 | 商业里程碑 |
|------|------|-----------|-----------|
| **Seed** | Y1 | 监控 MVP 上线（离岗/挂播/替身/活体）；算法备案 + 增值电信 | 付费账号 800；标杆 KA 直签；Y1 ARR ¥0.09 亿 |
| **A** | Y2 | 平台 API 对接；私有化部署；声纹/话术增强 | 付费账号 5,500；关键平台合作；ARR ¥0.61 亿 |

## §15.2 技术路线

- Y1–Y2：六模块算法栈调优至端到端 F1 ≥ 98.5%、告警 P99 ≤ 78s；推理成本年降 28%。
- Y3–Y4：数据飞轮累计标注 100 万→220 万小时；边缘-云协同降本；多平台适配。
- Y5+：上行扩展层（风控 OS / 数据网络 / 保险 RegTech）作为第二曲线评估。
