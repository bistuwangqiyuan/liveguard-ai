# §3 竞争分析与差异化定位

## §3.1 竞争格局

直播间合规监控目前由四类供给"半覆盖"，均存在明显短板：

| 竞争类别 | 代表 | 能力 | 短板 |
|---------|------|------|------|
| **平台自有治理** | 抖音/淘宝/快手风控 | 规则 + 抽检 | 仅覆盖自有平台、精度有限、不对外开放、无 Re-ID/活体 |
| **通用 CV / 大模型 API** | 云厂商视觉 API | 通用检测 | 非直播垂类、不识别挂播/替身、成本高、非实时取证 |
| **规则脚本 / 人工巡检** | MCN 自建 | 离岗计时 | 易被循环视频/数字人绕过、不可规模化 |
| **垂类监控 SaaS（新生）** | < 5 家未规模化 | 部分离岗监控 | 算法栈浅、无数据闭环、无合规取证链 |

## §3.2 守播的差异化护城河

![竞争定位与护城河](liveguard/docs/images/liveguard_moat.png)

1. **垂类算法栈深度**：人脸/人形/Re-ID/活体/声纹/行为六模块协同，针对"挂播/替身/数字人"等**对抗性作弊**专门优化（通用 CV 在这些场景评分仅 15–45，守播 90–95，见 §4）。
2. **数据飞轮**：5 年累计标注 220 万小时垂类数据 [§7]，对抗样本越多越准——后来者难以追赶。
3. **合规取证链**：事件→证据片段→处置→可审计报告，直接对接令117号的主体责任举证需求。
4. **算法备案 + 等保三级 + 私有化**：监管资质本身是壁垒，也是平台/大型 MCN 采购的硬门槛。
5. **中立第三方身份**：不隶属任一平台，可跨平台服务 MCN/品牌/监管，规避"平台既当裁判又当运动员"的信任问题。

## §3.3 竞争四象限

> 横轴：直播垂类深度（浅→深）；纵轴：合规取证与中立性（弱→强）。

- 平台治理：垂类深但中立性弱、不对外。
- 通用 CV：两轴均弱。
- 规则脚本：两轴均弱。
- **守播：垂类深 + 中立强**——独占右上象限。

## §3.4 竞争风险与应对（详见 §13）

| 风险 | 应对 |
|------|------|
| 平台自研对外开放 | 绑定中立第三方价值 + 跨平台 + 深耕 MCN/品牌侧；保持算法领先 1–2 代 |
| 大模型降维打击 | 大模型做"协同+补位"，垂直小模型在实时性/成本/可取证上不可替代 |
| 价格战 | 数据飞轮带来的精度差形成溢价；以 ROI（避免封号损失）而非单价竞争 |
